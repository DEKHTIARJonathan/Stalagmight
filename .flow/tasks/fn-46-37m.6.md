# Tests - Rust & Playwright

## Overview

Write comprehensive tests for the new MoveSegment command (Rust unit tests) and the toolbar UI tool groups (Playwright end-to-end tests).

## Rust Tests (`src-tauri/src/core/state/tests.rs`)

- `test_move_segment` - create 3 connected sections via merges, call MoveSegment, verify all 3 section_offsets updated
- `test_move_segment_isolated` - unconnected section is NOT moved
- `test_move_segment_with_closures` - sections connected via closures also move
- `test_move_segment_undo_redo` - undo restores all offsets, redo reapplies
- `test_move_segment_accumulates` - multiple MoveSegment calls accumulate offsets

## Playwright Tests (`e2e-playwright/`)

- Tool group UI: left-click activates last subtool, right-click opens flyout
- Cycling: left-click active group cycles to next subtool
- Flyout: clicking subtool activates it, clicking outside closes flyout
- Flyout keyboard: Arrow keys navigate, Enter selects, Escape closes
- Keyboard shortcuts: V activates move_segment, T activates move_station, G activates move_shot
- Anchored segment fading: sections with zero datum are faded when Move Segment tool is active
- Toolbar separators: thin vertical lines between tool groups are visible

## Files to Modify

- `src-tauri/src/core/state/tests.rs` (or appropriate test module)
- `e2e-playwright/` (new or existing test file for tool groups)

## Acceptance Criteria

- [ ] All 5 Rust MoveSegment tests pass: `cargo test --manifest-path src-tauri/Cargo.toml`
- [ ] Playwright tests for tool group UI interactions pass: `pnpm test:ui`
- [ ] Playwright tests for keyboard shortcuts pass
- [ ] No regressions in existing test suites
