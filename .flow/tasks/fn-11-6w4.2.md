# fn-11-6w4.2 Extend ExportImageOptions with color mode, preset, and legend fields

## Description
Extend ExportImageOptions struct in both Rust and TypeScript to support color mode, depth preset, and legend options.

**Depends on:** fn-11-6w4.1 (depth color module)

## Rust Changes

### Update `src-tauri/src/export/image.rs`
```rust
use super::depth_colors::DepthPreset;

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq, Default)]
#[serde(rename_all = "lowercase")]
pub enum ColorMode {
    #[default]
    Section,
    Depth,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ExportImageOptions {
    // Existing fields
    pub format: ImageFormat,
    pub dpi: u32,
    pub include_satellite: bool,
    pub include_grid: bool,
    pub include_labels: bool,
    pub include_section_names: bool,
    pub include_shot_data: bool,
    
    // NEW fields
    #[serde(default)]
    pub color_mode: ColorMode,
    #[serde(default)]
    pub depth_preset: DepthPreset,
    #[serde(default)]
    pub include_legend: bool,
}
```

Update `Default` impl:
```rust
impl Default for ExportImageOptions {
    fn default() -> Self {
        Self {
            format: ImageFormat::Png,
            dpi: 300,
            include_satellite: true,
            include_grid: false,
            include_labels: true,
            include_section_names: true,
            include_shot_data: false,
            color_mode: ColorMode::Section,
            depth_preset: DepthPreset::Thermal,
            include_legend: true,
        }
    }
}
```
