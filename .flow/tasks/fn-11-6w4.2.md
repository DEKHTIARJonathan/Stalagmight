# fn-11-6w4.2 Extend ExportImageOptions with color mode, preset, and legend fields

## Description
Extend ExportImageOptions struct to support color mode, depth preset, legend, and unit info.

**CRITICAL: Include depth_unit and decimal_precision from frontend config.**

## Rust Changes

### Update `src-tauri/src/export/image.rs`
```rust
use super::depth_colors::DepthPreset;

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq, Default)]
#[serde(rename_all = "lowercase")]
pub enum ColorMode {
    #[default]
    Section,
    Depth,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ExportImageOptions {
    // Existing fields
    pub format: ImageFormat,
    pub dpi: u32,
    pub include_satellite: bool,
    pub include_grid: bool,
    pub include_labels: bool,
    pub include_section_names: bool,
    pub include_shot_data: bool,
    
    // NEW fields
    #[serde(default)]
    pub color_mode: ColorMode,
    #[serde(default)]
    pub depth_preset: DepthPreset,
    #[serde(default)]
    pub include_legend: bool,
    #[serde(default = "default_depth_unit")]
    pub depth_unit: String,       // "m" or "ft" from frontend config
    #[serde(default = "default_precision")]
    pub decimal_precision: u8,    // From config.units.decimal_precision
}

fn default_depth_unit() -> String { "m".to_string() }
fn default_precision() -> u8 { 1 }
```
