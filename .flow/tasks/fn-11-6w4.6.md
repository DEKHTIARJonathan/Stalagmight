# fn-11-6w4.6 Add color mode and preset selectors to ExportDialog

## Description
Add color mode, preset, and legend selectors to ExportDialog.

**CRITICAL: Use useProjectStore (NOT useConfigStore - it doesn't exist). Handle config=null with explicit defaults.**

## Config Access with Null Fallback
```tsx
import { useProjectStore } from '../../store/projectStore';

const config = useProjectStore(state => state.config);

// CRITICAL: Explicit fallback when config is null
const depthUnit = config?.units?.depth ?? 'm';
const decimalPrecision = config?.display?.decimalPrecision ?? 1;

const handleExport = async () => {
  await exportImage(selected, { 
    ...imageOptions, 
    format: imageFormat,
    depth_unit: depthUnit === 'meters' ? 'm' : (depthUnit === 'feet' ? 'ft' : 'm'),
    decimal_precision: decimalPrecision,
  });
};
```

## Fetch Preset Colors (useEffect + invoke, NOT react-query)
```tsx
const [presetColors, setPresetColors] = useState<{ stops: Array<{ position: number; color: string }> } | null>(null);

useEffect(() => {
  if (imageOptions.color_mode === 'depth') {
    invoke<{ stops: Array<{ position: number; color: string }> }>('get_depth_preset_colors', { 
      preset: imageOptions.depth_preset 
    })
      .then(setPresetColors)
      .catch(err => console.error('Failed to fetch preset colors:', err));
  } else {
    setPresetColors(null);
  }
}, [imageOptions.color_mode, imageOptions.depth_preset]);
```
