## Approach

### New focus management tests (`e2e-playwright/focus-management.spec.ts`)

Test a representative sample of 3-5 dialogs:

1. **Tab cycling test** (NewProjectDialog — form dialog):
   - Open dialog, verify first input focused
   - Tab through all elements, verify wraps to first
   - Shift+Tab at first element, verify wraps to last

2. **Return focus test** (ConfirmDialog — non-form dialog):
   - Click button to open dialog, note trigger element
   - Close dialog via Escape
   - Verify focus returned to trigger button

3. **Stacked dialog isolation test** (dirty-confirm overlay):
   - Open a dialog that uses DialogWrapper's built-in dirty-confirm (e.g., EditShotDialog or NewProjectDialog with `isDirty={true}`) -- NOT SettingsDialog, which passes `isDirty={false}` and uses its own custom unsaved changes dialog without `useFocusTrap`
   - Make a change to set dirty state, then press Escape to trigger dirty-confirm overlay
   - Verify Tab is trapped in the overlay only (DialogWrapper disables the main dialog's focus trap via `useFocusTrap(dialogRef, { enabled: !showConfirm })` and activates the alertdialog's trap via `useFocusTrap(alertDialogRef, { enabled: showConfirm })`)
   - Outer dialog content has `inert` attribute while dirty-confirm is shown
   - Dismiss overlay, verify focus returns to outer dialog
<!-- Updated by plan-sync: fn-50-3j7.3 -- SettingsDialog passes isDirty={false} to DialogWrapper so its unsaved-changes dialog is custom and lacks useFocusTrap; use a dialog with isDirty={true} to test DialogWrapper's built-in dirty-confirm focus trap -->

4. **Initial focus test** (ConfirmDialog):
   - Open confirm dialog
   - Verify focus on primary action button (not Cancel)

5. **SettingsSidebar roving tabindex** (SettingsDialog):
   - Open SettingsDialog
   - Tab to reach sidebar
   - Arrow down/up through categories
   - Verify categories change and sidebar maintains focus

### Assertion approach

Use both `:focus` selector and `document.activeElement` for assertions:
```
await page.keyboard.press('Tab');
const focused = await page.evaluate(() => document.activeElement?.getAttribute('data-testid'));
```
