# fn-11-6w4.5 Generate depth legend SVG element with unit support

## Description
Generate depth legend SVG element using viewBox-relative units AND apply unit conversion to ALL depth labels.

**CRITICAL: Convert meters to feet when unit="ft" (not just suffix change). Applies to:**
- Legend min/max labels
- Shot depth labels (when include_shot_data=true)

## Unit Conversion Helper
```rust
fn format_depth_label(depth_meters: f64, unit: &str, precision: u8) -> String {
    let value = if unit == "ft" {
        depth_meters * 3.28084  // Convert meters to feet
    } else {
        depth_meters
    };
    format!("{:.prec$}{}", value, unit, prec = precision as usize)
}
```

## Legend Positioning (viewBox-relative units)
```rust
fn generate_depth_legend(
    min_depth: f64,
    max_depth: f64,
    preset: DepthPreset,
    depth_unit: &str,
    precision: u8,
    bounds: &Bounds,
) -> String {
    // Size relative to project extent (in meters/user units)
    let legend_width = (bounds.width() * 0.02).max(1.0);   // 2% of width, min 1m
    let legend_height = (bounds.height() * 0.15).max(5.0); // 15% of height, min 5m
    let font_size = (bounds.height() * 0.02).max(0.8);     // Relative font size
    
    // Position: top-right corner with padding
    let padding = bounds.width() * 0.02;
    let x = bounds.max_x - legend_width - padding;
    let y = -(bounds.max_y - padding);  // Note: Y is flipped in SVG
    
    // Multi-stop gradient for all presets (matches backend interpolation)
    let colors = preset.colors();
    let gradient_stops: String = colors.stops.iter().map(|stop| {
        format!(r#"<stop offset="{}%" stop-color="{}"/>"#, 
            stop.position * 100.0, stop.color)
    }).collect::<Vec<_>>().join("\n    ");
    
    let is_flat = (max_depth - min_depth).abs() < 0.1;
    let flat_suffix = if is_flat { " (Flat)" } else { "" };
    
    // Use format_depth_label for unit conversion
    let min_label = format_depth_label(min_depth, depth_unit, precision);
    let max_label = format_depth_label(max_depth, depth_unit, precision);
    
    format!(r#"
<defs>
  <linearGradient id="depth-gradient" x1="0%" y1="0%" x2="0%" y2="100%">
    {}
  </linearGradient>
</defs>
<g class="depth-legend" transform="translate({:.2}, {:.2})">
  <rect width="{:.2}" height="{:.2}" fill="url(#depth-gradient)" stroke="#333" stroke-width="0.1"/>
  <text x="{:.2}" y="-0.3" text-anchor="middle" font-size="{:.2}" fill="#fff">{}{}</text>
  <text x="{:.2}" y="{:.2}" text-anchor="middle" font-size="{:.2}" fill="#fff">{}</text>
</g>"#,
        gradient_stops,
        x, y,
        legend_width, legend_height,
        legend_width / 2.0, font_size, min_label, flat_suffix,
        legend_width / 2.0, legend_height + font_size + 0.2, font_size, max_label
    )
}
```

## Legend Positioning
```rust
struct Bounds {
    min_x: f64,
    max_x: f64,
    min_y: f64,
    max_y: f64,
}

impl Bounds {
    fn width(&self) -> f64 { self.max_x - self.min_x }
    fn height(&self) -> f64 { self.max_y - self.min_y }
}

fn generate_depth_legend(
    min_depth: f64,
    max_depth: f64,
    preset: DepthPreset,
    depth_unit: &str,
    precision: u8,
    bounds: &Bounds,
) -> String {
    // Size relative to project extent (in meters/user units)
    let legend_width = (bounds.width() * 0.02).max(1.0);   // 2% of width, min 1m
    let legend_height = (bounds.height() * 0.15).max(5.0); // 15% of height, min 5m
    let font_size = (bounds.height() * 0.02).max(0.8);     // Relative font size
    
    // Position: top-right corner with padding
    let padding = bounds.width() * 0.02;
    let x = bounds.max_x - legend_width - padding;
    let y = -(bounds.max_y - padding);  // Note: Y is flipped in SVG
    
    // Build gradient
    let gradient_id = "depth-gradient";
    let colors = preset.colors();
    
    // For thermal, use multi-stop gradient
    let gradient_stops = match preset {
        DepthPreset::Thermal => r#"
    <stop offset="0%" stop-color="#00bfff"/>
    <stop offset="25%" stop-color="#00ffaa"/>
    <stop offset="50%" stop-color="#44ff00"/>
    <stop offset="75%" stop-color="#ffff00"/>
    <stop offset="100%" stop-color="#ff4444"/>"#.to_string(),

    <stop offset="0%" stop-color="{}"/>
    <stop offset="100%" stop-color="{}"/>"#, colors.shallow, colors.deep),
    };
    
    let is_flat = (max_depth - min_depth).abs() < 0.1;
    let flat_suffix = if is_flat { " (Flat)" } else { "" };
    
    format!(r#"
<defs>
  <linearGradient id="{}" x1="0%" y1="0%" x2="0%" y2="100%">{}</linearGradient>
</defs>
<g class="depth-legend" transform="translate({:.2}, {:.2})">
  <rect width="{:.2}" height="{:.2}" fill="url(#{})" stroke="#333" stroke-width="0.1"/>
  <text x="{:.2}" y="-0.3" text-anchor="middle" font-size="{:.2}" fill="#fff">{:.precision$}{}{}</text>
  <text x="{:.2}" y="{:.2}" text-anchor="middle" font-size="{:.2}" fill="#fff">{:.precision$}{}</text>
</g>"#,
        gradient_id, gradient_stops,
        x, y,
        legend_width, legend_height, gradient_id,
        legend_width / 2.0, font_size, min_depth, depth_unit, flat_suffix,
        legend_width / 2.0, legend_height + font_size + 0.2, font_size, max_depth, depth_unit,
        precision = precision as usize
    )
}
```
## Legend Design

Vertical gradient bar positioned in top-right corner:
- Dimensions: 16px wide × 80px tall
- Shallow color at top, deep color at bottom
- Min depth label at top, max depth label at bottom
- Unit suffix from config.units.depth (m or ft)

## Implementation

Add to `src-tauri/src/export/image.rs`:

```rust
fn generate_depth_legend(
    min_depth: f64,
    max_depth: f64,
    preset: DepthPreset,
    depth_unit: &str,
    svg_width: f64,
) -> String {
    let colors = preset.colors();
    let x = svg_width - 40.0; // 40px from right edge
    let y = 20.0; // 20px from top
    let bar_width = 16.0;
    let bar_height = 80.0;
    
    // Gradient definition
    let gradient_id = "depth-gradient";
    let gradient = format!(
        r#"<defs>
  <linearGradient id="{}" x1="0%" y1="0%" x2="0%" y2="100%">
    <stop offset="0%" style="stop-color:{};stop-opacity:1" />
    <stop offset="100%" style="stop-color:{};stop-opacity:1" />
  </linearGradient>
</defs>"#,
        gradient_id, colors.shallow, colors.deep
    );
    
    // Legend group
    let is_flat = (max_depth - min_depth).abs() < 0.1;
    let label_suffix = if is_flat { " (Flat)" } else { "" };
    
    format!(
        r#"{gradient}
<g class="depth-legend" transform="translate({x}, {y})">
  <rect width="{bar_width}" height="{bar_height}" fill="url(#{gradient_id})" stroke="#333" stroke-width="1"/>
  <text x="{}" y="-4" text-anchor="middle" class="legend-label">{:.1}{}{}</text>
  <text x="{}" y="{}" text-anchor="middle" class="legend-label">{:.1}{}</text>
</g>"#,
        bar_width / 2.0, min_depth, depth_unit, label_suffix,
        bar_width / 2.0, bar_height + 14.0, max_depth, depth_unit
    )
}
```
