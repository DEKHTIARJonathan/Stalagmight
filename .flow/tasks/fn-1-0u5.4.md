## Summary
Added three IPC commands for cache management:

1. **get_cache_stats** - Returns CacheStats with total_tiles, total_bytes, and per-provider breakdown
2. **clear_tile_cache** - Clears all cached tiles or tiles for a specific provider
3. **get_network_status** - Checks network connectivity (returns true for HTTP responses, even 4xx/5xx)

- Created `src-tauri/src/commands/cache.rs` with CacheStats, ProviderStats structs
- Extended TileCache with `stats()` and `clear_provider()` methods
- Used `incremental_vacuum` instead of blocking VACUUM for better performance
- Registered commands in lib.rs invoke_handler
- Derived totals from provider map for internal consistency
