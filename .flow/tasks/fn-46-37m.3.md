# Keyboard Shortcuts for New Tools

## Overview

Add keyboard shortcuts for the new `move_segment` and `move_shot` tools, reassign the `V` shortcut from `move_section` to `move_segment`, and update all config layers (Rust defaults, TypeScript types, keyboard handler, settings UI).

## Steps

### 5a. Reassign V shortcut

- `V` = `move_segment` (was `move_section`)
- `Shift+V` = `move_section`

### 5b. Add new shortcut

- `G` = `move_shot`
- `T` = `move_station` (unchanged)

### 5c. Update config types

- **Rust**: `src-tauri/src/config/types.rs` - add `move_segment`, `move_shot` to ShortcutsConfig
- **Rust**: `src-tauri/src/config/defaults.rs` - set default key bindings: `move_segment: "V"`, `move_section: "Shift+V"`, `move_shot: "G"`
- **TypeScript**: `src/types/config.ts` - mirror changes in ShortcutsConfig type
- **Hook**: `src/hooks/useKeyboardShortcuts.ts` - add to ShortcutAction, ACTION_LABELS, buildShortcutMap, handleKeyDown
- **Settings**: `src/components/Dialogs/settings/ShortcutsSettings.tsx` - display new shortcuts in the settings panel
