### Protocol handler registration
```rust
.register_asynchronous_uri_scheme_protocol("cavechef-tiles", |ctx, request, responder| {
    let state = ctx.app_handle().state::<AppState>();
    let path = request.uri().path(); // /esri/{z}/{y}/{x}
    
    std::thread::spawn(move || {
        // Parse z/y/x from path
        // Check cache
        // If miss, fetch from ESRI URL
        // Cache the result
        // Respond with tile data
    });
})
```

### Tile URL format
- Request: `cavechef-tiles://esri/{z}/{y}/{x}`
- ESRI source: `https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}`

## Error handling
- Network timeout: 10 seconds
- On fetch error: return 404 if no cached tile
- On parse error: return 400 Bad Request
