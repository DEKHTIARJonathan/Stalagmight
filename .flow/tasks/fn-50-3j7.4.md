# Task: Add return-focus-on-close to DialogWrapper

## Description

When a dialog closes, return keyboard focus to the element that was focused before the dialog opened.

### Requirements

1. **Capture trigger**: On mount, store `document.activeElement` as the trigger element in a `useRef`.
2. **Restore on unmount**: In the cleanup function of a `useEffect`, call `triggerRef.current?.focus()` if the element is still in the DOM (`document.contains(triggerRef.current)`).
3. **Graceful fallback**: If the trigger element has been removed from the DOM (e.g., a row was deleted), do nothing — let the browser's default focus behavior apply.
4. **Nested dialogs**: If a dialog opens another dialog (e.g., Settings -> nested dialog), each dialog independently captures and restores its own trigger.

### Files to modify

- `src/components/Dialogs/DialogWrapper.tsx`

## Acceptance Criteria

- [ ] After closing a dialog, focus returns to the button/element that opened it.
- [ ] If the trigger element was removed while the dialog was open, no error occurs.
- [ ] Nested dialog close restores focus to the inner trigger, not the outer one.
- [ ] `pnpm tsc --noEmit` passes.
