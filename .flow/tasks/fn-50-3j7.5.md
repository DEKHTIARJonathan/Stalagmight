# Task: Add --cc-focus-ring CSS variable and replace hardcoded #4ecdc4

## Description

Define a `--cc-focus-ring` CSS custom property in `index.css` and replace all hardcoded `#4ecdc4` focus-ring color references throughout the codebase.

### Requirements

1. **Define variable**: In `src/index.css`, add `--cc-focus-ring: #4ecdc4;` to the `:root` selector (or the appropriate theme block).
2. **Search and replace**: Find all files referencing `#4ecdc4` in focus-ring contexts and replace with `var(--cc-focus-ring)`.
3. **Known files** (from grep): `src/index.css`, `src/utils/colors.ts`, `src/components/Map/SurveyLayer.tsx`, `src/components/Dialogs/SectionPreview.tsx`, `src/hooks/useImportState.ts`, `src/components/Dialogs/EditSectionDialog.tsx`, `src/components/common/SectionMetadataForm.tsx`, `src/types/config.ts`.
4. **Audit each usage**: Not all `#4ecdc4` usages may be focus-ring related (some may be map highlight colors). Only replace focus-ring/outline usages. Leave non-focus usages as-is but add a comment `/* TODO: consider extracting to CSS variable */` if appropriate.
5. **Spec already mentions `--cc-focus-ring`** in Section 11.4 — verify this is consistent.

### Files to modify

- `src/index.css` (primary)
- Various TSX/TS files with `#4ecdc4` focus-ring references

## Acceptance Criteria

- [ ] `--cc-focus-ring` is defined in `:root` in `src/index.css`.
- [ ] All focus-ring outline usages of `#4ecdc4` use `var(--cc-focus-ring)` instead.
- [ ] Non-focus usages of `#4ecdc4` are left alone or annotated.
- [ ] Visual appearance is unchanged (same color, just tokenized).
- [ ] `pnpm tsc --noEmit` passes.
