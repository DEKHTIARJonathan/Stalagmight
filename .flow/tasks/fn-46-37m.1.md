# Type System & Tool Group Definitions

## Overview

Extend the ToolType union with two new tools (`move_segment`, `move_shot`), create a tool group definitions module, add group-aware state to uiStore, and update all touch points that reference tool types.

## Steps

### 1a. Extend ToolType (`src/store/uiStore.ts:16`)

Add `move_segment` and `move_shot` to the ToolType union:

```typescript
export type ToolType =
  | 'select' | 'pan' | 'zoom' | 'draw'
  | 'delete' | 'merge' | 'measure'
  | 'move_section' | 'move_station'
  | 'move_segment' | 'move_shot';
```

### 1b. Create tool group definitions (`src/utils/toolGroups.ts` - new file)

```typescript
export interface ToolGroupDef {
  id: string;
  tools: ToolType[];
  defaultTool: ToolType;
}

export const TOOL_GROUPS: ToolGroupDef[] = [
  { id: 'navigate', tools: ['pan', 'zoom'], defaultTool: 'pan' },
  { id: 'move', tools: ['move_segment', 'move_section', 'move_shot', 'move_station'], defaultTool: 'move_segment' },
];
```

Helper functions needed:
- `getGroupForTool(tool: ToolType): ToolGroupDef | undefined`
- `isGroupedTool(tool: ToolType): boolean`
- `getStandaloneTools(): ToolType[]` (returns tools not in any group)

### 1c. Add group-aware state to uiStore

Add `lastSubtoolByGroup: Record<string, ToolType>` to the store. When `setActiveTool` is called with a grouped tool, update `lastSubtoolByGroup[groupId]`.

### 1d. Update touch points for new tool types

- `src/utils/toolUtils.ts` - move tools are NOT non-interactive (they need station/shot clicks)
- `src/components/Map/MapCanvas.tsx:21` - new move tools NOT in CTRL_PAN_TOOLS
- Cursor maps in MapCanvas - add `move_segment: 'move'`, `move_shot: 'move'`
- Icon map in `Toolbar.tsx` - add icons for new tools
