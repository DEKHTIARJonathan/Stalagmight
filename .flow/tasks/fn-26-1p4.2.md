## Description

Update Playwright tests that assume markers are always visible in default (survey) mode, and add new tests covering the marker visibility lifecycle. Also update project documentation (SPEC.md and architecture.md) to reflect the new behavior.

**Size:** M
**Files:** `e2e-playwright/globalview-map.spec.ts`, `docs/SPEC.md`, `docs/architecture.md`

## Approach

### Test updates

Existing tests at `globalview-map.spec.ts:89-99` expect markers always visible. Update to account for survey mode hiding loaded-geometry markers:
- Tests that count markers need to either switch to markers mode first, or use appropriate selectors
- Use `el.style.display` checks or Playwright `:visible` pseudo-class for visibility assertions (since visibility is toggled via inline `display` style, not CSS class)

### New tests to add

- Survey mode: markers hidden after geometry loads (check `display: none` on marker element)
- Survey mode: spinner markers visible during loading
- Survey mode: error markers visible on load failure
- Markers mode: all markers visible (check `:visible` or `display: flex`)
- Mode toggle: markers appear/disappear instantly on toggle click

### Doc updates

- `docs/SPEC.md` lines 414-421: Update "Survey Rendering" bullet about lazy loading markers to note markers hidden when geometry loaded; update "View Mode Toggle" to describe marker visibility behavior per mode
- `docs/architecture.md` lines 155-163: Update view mode comment from "markers as fallback while loading" to describe conditional visibility (hidden when loaded in survey mode, always visible in markers mode)

### Patterns to follow

- Follow existing test patterns in `e2e-playwright/` (data-testid selectors, timeout patterns)
- Test selector: `.globalview-system-marker` CSS class, `data-testid="system-marker-{filePath}"`
- View mode toggle: verify toggle button testid exists
- Current marker test at `globalview-map.spec.ts:91-92`: `const markers = page.locator('.globalview-system-marker'); await expect(markers).toHaveCount(3)`

## Key context

- Visibility is toggled via inline `el.style.display` (`'none'` / `'flex'`), NOT via CSS class. Playwright `:visible` pseudo-class will work since `display: none` elements are not visible.
- Current marker test at `globalview-map.spec.ts:91-92` expects 3 markers always visible — needs update.
- View mode toggle data-testid needs to be verified before writing tests.
