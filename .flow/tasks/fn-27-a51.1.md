# fn-27-a51.1 Add fixedSize prop to DialogWrapper and apply to SettingsDialog

## Description

Add an optional `fixedSize` prop to `DialogWrapper` that accepts `{ width: string; height: string }`. When provided, it overrides both `size` and `maxHeight` props, applying CSS `min()`/`clamp()` for responsive fallback. Then apply it to `SettingsDialog` so the dialog maintains constant dimensions regardless of active category.

Also add scroll-to-top reset on category change using a ref on the content area div, and clean up redundant sizing classes.

**Size:** M
**Files:**
- `src/components/Dialogs/DialogWrapper.tsx` — add `FixedSize` interface + `fixedSize` prop + conditional className logic
- `src/components/Dialogs/SettingsDialog.tsx` — pass `fixedSize`, add scroll ref + reset in `handleCategoryChange`, remove `min-h-[500px]`, change `min-w-[600px]` to `min-w-[500px]`

## Approach

- Follow existing prop pattern in `DialogWrapper.tsx:16-30` (size, maxHeight, overflow)
- Add `FixedSize` interface: `{ width: string; height: string }` — both required
- When `fixedSize` is provided, apply inline style or Tailwind arbitrary values for width (`min(800px,_95vw)`) and height (`clamp(500px,_80vh,_800px)`), bypassing `sizeClasses[size]` and `maxHeight`
- Responsive fallback is built into CSS `min()`/`clamp()` — no JS viewport detection
- In `SettingsDialog.tsx`, add `useRef<HTMLDivElement>` on the scrollable content div at line 561
- In `handleCategoryChange` (line 360), add `contentRef.current.scrollTop = 0`
- Remove `min-h-[500px]` from inner container (line 531) — clamp handles minimum
- Change `min-w-[600px]` → `min-w-[500px]` on inner container
- Tailwind arbitrary value syntax: use underscores for spaces (e.g., `h-[clamp(500px,_80vh,_800px)]`)

## Risks / Dependencies

- **fn-25-itw overlap**: That epic also references `DialogWrapper.tsx` for ErrorDialog wrapping. This change is additive (new optional prop) so conflict risk is low. If both land close together, a simple merge resolves it.
- **Existing dialogs**: `fixedSize` is optional and defaults to undefined — all 18+ existing DialogWrapper consumers are unaffected.
- **Tailwind JIT**: Arbitrary values with `clamp()`/`min()` are supported in Tailwind 3.4.15. Underscores replace spaces.
