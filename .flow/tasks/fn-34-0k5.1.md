# fn-34-0k5.1 Add onOptionHover prop to Select and wire DataTable section dropdown

## Description

Add `onOptionHover?: (value: string | null) => void` callback prop to the Select component. Fire the callback on mouse hover and keyboard navigation (ArrowDown, ArrowUp, Home, End). Fire `null` on all dropdown close paths. Wire the callback in DataTable's section dropdown to `setHoveredSectionId` for map highlighting.

**Size:** M
**Files:**
- `src/components/common/Select.tsx` (add prop, modify event handlers)
- `src/components/SingleSystemView/DataTable.tsx` (wire onOptionHover to setHoveredSectionId)

## Approach

### Select.tsx changes

1. Add `onOptionHover?: (value: string | null) => void` to `SelectProps` interface (after line 37)

2. **Mouse hover**: In `renderOption()`, extend the existing `onMouseEnter` handler at line 324. After setting `highlightedIndex`, call `onOptionHover?.(option.value)`. The existing `!option.disabled` guard already applies.

3. **Keyboard navigation**: In the `onKeyDown` handler (lines 219-294), after each navigation case (ArrowDown, ArrowUp, Home, End) that computes a new `highlightedIndex`, resolve the corresponding option value from `flatOptions` and call `onOptionHover?.(value)`. Skip disabled options (already handled by existing `findNextEnabledIndex` logic).

4. **Close paths**: Add `onOptionHover?.(null)` call to:
   - `handleSelect()` function (option selected via click/Enter/Space)
   - Outside-click useEffect handler (lines 136-148)
   - Escape key case (lines 276-285)
   - Tab key case (lines 287-292)

5. **No intermediate nulls**: Call `onOptionHover` directly from event handlers, not from a `useEffect` on `highlightedIndex`. This prevents render-cycle delays and intermediate null states.

### DataTable.tsx changes

1. Create `handleSectionHover` callback that:
   - When value is non-null: converts string to number via `Number(value)`, calls `setHoveredSectionId(sectionId)`
   - When value is null: calls `setHoveredSectionId(null)`
   - Tracks last hover ID in a ref (matching `SectionsPanel.tsx:12-30` pattern)

2. Pass `onOptionHover={handleSectionHover}` to the section Select at lines 429-434

3. Add ref-based unmount cleanup: track last-hovered ID in `lastHoveredSectionIdRef`, clear on unmount only if store value matches (follow `SectionsPanel.tsx:12-30` exactly)

### Key context

- **SectionId can be 0**: Use `!== null` checks, never truthiness. `Number("0")` correctly returns 0.
- **Stale closures pitfall**: If `onOptionHover` is used in setTimeout/async code, track in a ref (project memory).
- **Mouse leave + keyboard**: When combining mouse hover and keyboard focus, mouse leave must check if keyboard focus is active before clearing (project memory pitfall). For Select, this is handled by not firing null between options — only on dropdown close.
- **flatOptions**: Select.tsx already flattens grouped options into `flatOptions` array. Use this to resolve option values from `highlightedIndex`.
