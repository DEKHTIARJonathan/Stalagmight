# Task: Add Playwright tests for focus management

## Description

Write Playwright end-to-end tests that verify focus trap cycling, initial focus placement, return focus on close, and nested alertdialog focus behavior.

### Requirements

1. **Focus trap cycling test**: Open a dialog, Tab through all focusable elements, verify Tab at the last element wraps to the first. Verify Shift+Tab at the first wraps to the last.
2. **Initial focus test (form dialog)**: Open a form dialog (e.g., EditSectionDialog), verify focus is on the first input.
3. **Initial focus test (non-form dialog)**: Open a non-form dialog, verify focus is on the primary action button.
4. **Return focus test**: Click a button to open a dialog, close the dialog, verify focus returns to the button.
5. **Nested alertdialog test**: Open a dialog, make it dirty, press Escape, verify the alertdialog appears and Tab is trapped within it. Verify the outer dialog has `inert`. Cancel the alertdialog, verify focus returns to the outer dialog and `inert` is removed.
6. **Test file location**: Follow existing test patterns in the project (check `tests/` or `e2e/` directory).

### Files to create/modify

- New or existing Playwright test file for focus management

## Acceptance Criteria

- [ ] At least 5 test cases covering the scenarios above.
- [ ] All tests pass with `pnpm test:ui`.
- [ ] Tests use accessible locators (role, label) where possible.
