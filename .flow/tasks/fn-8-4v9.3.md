# fn-8-4v9.3 Wire setActiveTool in MapCanvas useEffect

## Description
Wire up setActiveTool call in MapCanvas when activeTool changes.

## Implementation

Add useEffect in MapCanvas.tsx:

```typescript
// After the existing surveyLayerRef useEffects
useEffect(() => {
  if (surveyLayerRef.current) {
    surveyLayerRef.current.setActiveTool(activeTool);
  }
}, [activeTool]);
```

This ensures:
1. SurveyLayer knows the current tool at all times
2. Hover state is cleared when switching to pan/zoom
3. Visual state is updated immediately on tool switch
