# fn-8-4v9.3 Wire setActiveTool in MapCanvas useEffect

## Description
Wire up setActiveTool call in MapCanvas when activeTool changes.

## Implementation

**CRITICAL**: Also depend on `mapLoaded` to handle the case where tool changed before map loaded.

```typescript
// Wire up setActiveTool - depend on mapLoaded to ensure it runs after layer creation
useEffect(() => {
  if (surveyLayerRef.current) {
    surveyLayerRef.current.setActiveTool(activeTool);
  }
}, [activeTool, mapLoaded]);  // mapLoaded ensures this runs after layer is created
```

**Alternative approach** (can do both for safety): Also set tool immediately after creating SurveyLayer in the map load handler:

```typescript
// In map 'load' handler:
surveyLayerRef.current = new SurveyLayer(map.current, toolCallbacks);
surveyLayerRef.current.setActiveTool(useUIStore.getState().activeTool);  // Set initial tool
```

This ensures:
1. SurveyLayer knows the current tool at all times
2. Hover state is cleared when switching to pan/zoom
3. isHoveringFeature is cleared via callbacks
4. Tool is set correctly even if changed before map loaded
## Implementation

// After the existing surveyLayerRef useEffects
useEffect(() => {

This ensures:
