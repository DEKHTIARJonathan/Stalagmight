# Toolbar UI - Tool Group Buttons

## Overview

Redesign the toolbar to support Photoshop-style tool groups. Grouped tools show a single button with a small triangle indicator; left-click activates the last-used subtool (or cycles if the group is already active); right-click opens a flyout panel listing all subtools.

## Steps

### 4a. ToolGroupButton component (`src/components/SingleSystemView/Toolbar.tsx`)

New component with:
- **Left-click**: If group is not active, activate the last-used subtool. If group IS already active, cycle to the next subtool in the group.
- **Right-click (contextmenu)**: Toggle a flyout showing all subtools
- **Visual**: Small triangle indicator (bottom-right corner CSS pseudo-element) on grouped buttons
- **Active state**: Button shows as active if ANY subtool in the group is the active tool
- **Icon/tooltip**: Shows the currently active subtool's icon and name

### 4b. Flyout panel

Simple absolutely-positioned div below the button:
- Lists all subtools with icon + name + shortcut key
- Active subtool highlighted
- Click outside or click a subtool to close
- `data-testid="subtool-flyout-{groupId}"`
- **Keyboard accessibility**: Arrow keys navigate between subtools, Enter selects, Escape closes
- Focus management: when flyout opens, focus moves to the active subtool item

### 4c. Refactor toolbar layout

The tools array changes from a flat list to a mixed list of standalone tools and group references:

```
[Select] | [Navigate ▾] | [Draw] [Delete] [Merge] [Measure] | [Move ▾]
```

Where `|` is a **thin vertical line separator** (like the existing `<div className="w-px h-6 bg-border mx-2" />` pattern used elsewhere in Toolbar.tsx). Standalone tools render as before, groups render as ToolGroupButton.

### 4d. Icons for new tools

```typescript
move_segment: '⇔',  // double-headed arrow for connected movement
move_shot: '↗',     // diagonal arrow for shot direction
```
