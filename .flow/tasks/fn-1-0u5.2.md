## Key implementation

### Schema
```sql
CREATE TABLE tiles (
    id INTEGER PRIMARY KEY,
    provider TEXT NOT NULL,
    z INTEGER NOT NULL, y INTEGER NOT NULL, x INTEGER NOT NULL,
    data BLOB NOT NULL,
    content_type TEXT NOT NULL DEFAULT 'image/jpeg',
    size_bytes INTEGER NOT NULL,
    fetched_at INTEGER NOT NULL,
    accessed_at INTEGER NOT NULL,
    UNIQUE(provider, z, y, x)
);
CREATE INDEX idx_tiles_accessed ON tiles(accessed_at);
```

### TileCache struct
```rust
impl TileCache {
    pub fn open(cache_dir: &Path, max_mb: u32, ttl_days: u32) -> Result<Self>;
    pub fn get(&mut self, provider: &str, z: u32, y: u32, x: u32) -> Option<TileEntry>;
    pub fn put(&mut self, provider: &str, z: u32, y: u32, x: u32, data: &[u8], content_type: &str) -> Result<()>;
    pub fn evict_lru(&mut self) -> Result<u64>; // returns bytes freed
    pub fn clear_all(&mut self) -> Result<()>;
    pub fn clear_provider(&mut self, provider: &str) -> Result<()>;
    pub fn get_stats(&self) -> CacheStats;
}
```

## Unit tests (~15 tests)
- put and get roundtrip
- cache miss returns None
- LRU eviction (exceed max_mb, verify oldest evicted)
- TTL expiration (stale tiles not returned)
- clear_all removes all tiles
- clear_provider only removes specified provider
- cache_stats returns correct counts
- concurrent access (multi-threaded)
- different providers isolation
- zero-byte tile handling
- content-type preservation
- accessed_at updates on get
