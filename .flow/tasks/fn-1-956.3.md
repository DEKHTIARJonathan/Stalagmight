### Requirements for WebdriverIO to run
1. Linux with display (X11/Wayland) or xvfb
2. WebKitGTK 4.1 runtime libraries (usually included with GTK desktop)
3. tauri-driver (`cargo install tauri-driver`) - bridges WebDriver to Tauri/WebKitGTK
4. Hardware acceleration or software rendering (mesa/llvmpipe)

To run on a capable environment:
```bash
# Install dependencies (Ubuntu/Debian)
sudo apt-get install -y libwebkit2gtk-4.1-0 xvfb

# Install tauri-driver (handles WebDriver protocol for Tauri apps)
cargo install tauri-driver

# Build the app
pnpm tauri build --debug --no-bundle

# Run tests
xvfb-run --auto-servernum pnpm test:e2e
```
