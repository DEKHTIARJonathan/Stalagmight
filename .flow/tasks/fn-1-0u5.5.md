### MapLibre addProtocol registration
- `src/components/Map/MapCanvas.tsx` - Add useEffect for protocol registration

```typescript
useEffect(() => {
    maplibregl.addProtocol('cavechef-tiles', async (params, abortController) => {
        const response = await fetch(params.url, { signal: abortController.signal });
        return { data: await response.arrayBuffer() };
    });
    return () => maplibregl.removeProtocol('cavechef-tiles');
}, []);
```
