### Single In-Flight Load (cancel previous)

**IMPORTANT**: Only one load can be active at a time. Starting a new load cancels any in-progress load.

```rust
impl AppState {
    /// Cancel any active load and create new cancellation token
    /// Returns the token for the new load
    pub fn start_new_load(&self) -> Arc<AtomicBool> {
        let mut active = self.active_loading.lock().unwrap();
        
        // Cancel any existing load first
        if let Some(prev) = active.as_ref() {
            prev.store(true, Ordering::SeqCst);
        }
        
        // Create new token for this load
        let token = Arc::new(AtomicBool::new(false));
        *active = Some(token.clone());
        token
    }
    
    /// Clear active loading (called when load completes)
    pub fn clear_active_load(&self) {
        *self.active_loading.lock().unwrap() = None;
    }
}
```

## Key Design Notes

1. **Single in-flight load**: Only one load at a time. If user triggers a new load while one is in progress, the old one is cancelled automatically.
2. **AppHandle accessor pattern**: `get_app_handle()` clones and releases lock immediately to avoid deadlocks.
3. **start_new_load()**: Cancels previous load before creating new token - ensures clean handoff.
4. **Thread safety**: All new fields use Mutex for thread-safe access from spawn_blocking.

## Key Design Notes

1. **AppHandle accessor pattern**: `get_app_handle()` clones and releases lock immediately to avoid deadlocks when emitting events from within loops
2. **Per-load cancellation**: Each ProgressEmitter owns its own Arc<AtomicBool>, stored in active_loading for cancel_loading command access
3. **Scoped tokens**: Not using a shared token that gets reset - each load has its own token to avoid race conditions with concurrent loads
4. **Thread safety**: All new fields use Mutex for thread-safe access from spawn_blocking

## Modify: src-tauri/src/core/loading.rs

Add CancellationToken and integrate with ProgressEmitter:

```rust
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;

#[derive(Clone)]
pub struct CancellationToken {
    cancelled: Arc<AtomicBool>,
}

impl CancellationToken {
    pub fn new() -> Self {
        Self {
            cancelled: Arc::new(AtomicBool::new(false)),
        }
    }

    pub fn cancel(&self) {
        self.cancelled.store(true, Ordering::SeqCst);
    }

    pub fn is_cancelled(&self) -> bool {
        self.cancelled.load(Ordering::SeqCst)
    }
}

impl ProgressEmitter {
    pub fn with_cancellation(app_handle: AppHandle, token: CancellationToken) -> Self {
        Self {
            app_handle,
            completed_weight: 0.0,
            current_phase_weight: 0.0,
            cancellation_token: Some(token),
        }
    }

    pub fn check_cancelled(&self) -> Result<(), CancelledError> {
        if let Some(ref token) = self.cancellation_token {
            if token.is_cancelled() {
                return Err(CancelledError);
            }
        }
        Ok(())
    }
}

#[derive(Debug)]
pub struct CancelledError;
```
