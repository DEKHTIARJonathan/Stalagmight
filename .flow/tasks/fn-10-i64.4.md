# fn-10-i64.4 Add cancellation token support

## Description
Add cancellation token support for aborting project loading.

## Prerequisite
Task fn-10-i64.1 must be complete.

## Approach

Use an atomic boolean flag that can be checked between phases.

## Modify: src-tauri/src/core/loading.rs

Add CancellationToken and integrate with ProgressEmitter:

```rust
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;

#[derive(Clone)]
pub struct CancellationToken {
    cancelled: Arc<AtomicBool>,
}

impl CancellationToken {
    pub fn new() -> Self {
        Self {
            cancelled: Arc::new(AtomicBool::new(false)),
        }
    }

    pub fn cancel(&self) {
        self.cancelled.store(true, Ordering::SeqCst);
    }

    pub fn is_cancelled(&self) -> bool {
        self.cancelled.load(Ordering::SeqCst)
    }
}

impl ProgressEmitter {
    pub fn with_cancellation(app_handle: AppHandle, token: CancellationToken) -> Self {
        Self {
            app_handle,
            completed_weight: 0.0,
            current_phase_weight: 0.0,
            cancellation_token: Some(token),
        }
    }

    pub fn check_cancelled(&self) -> Result<(), CancelledError> {
        if let Some(ref token) = self.cancellation_token {
            if token.is_cancelled() {
                return Err(CancelledError);
            }
        }
        Ok(())
    }
}

#[derive(Debug)]
pub struct CancelledError;
```

## New Command: src-tauri/src/commands/project.rs

Add command to cancel loading:

```rust
#[tauri::command]
pub fn cancel_loading(state: State<AppState>) {
    if let Some(token) = state.get_cancellation_token() {
        token.cancel();
    }
}
```
