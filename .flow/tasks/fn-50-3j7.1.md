## Description

Create two new utility modules: a standalone focus trap hook and a dialog stack manager.

**Size:** M
**Files:** `src/hooks/useFocusTrap.ts`, `src/utils/dialogStack.ts`, `src/hooks/index.ts`

## Approach

### useFocusTrap hook (`src/hooks/useFocusTrap.ts`)

- Signature: `useFocusTrap(containerRef: RefObject<HTMLElement>, options?: { enabled?: boolean })`
- On each Tab/Shift+Tab keypress, re-query all focusable elements within the container (handles dynamic content)
- Comprehensive focusable selector: `a[href], button:not(:disabled), input:not(:disabled), textarea:not(:disabled), select:not(:disabled), [tabindex]:not([tabindex="-1"]), [contenteditable], audio[controls], video[controls], details > summary`
- Exclude elements inside `[inert]` and `[aria-hidden="true"]` subtrees
- Tab at last element wraps to first; Shift+Tab at first wraps to last
- `enabled` option (default true) to conditionally disable
- Attach keydown listener to the container element (not document)
- Follow existing hook patterns in `src/hooks/` — export from `index.ts`
- Handle React Strict Mode double-invoke: cleanup must remove listeners, clear timeouts

### dialogStack utility (`src/utils/dialogStack.ts`)

- Module-level array tracks open dialog container elements
- Imperative API: `pushDialog(element)`, `popDialog(element)`, `isTopmost(element)`
- `pushDialog`: (a) add element to stack, (b) set `inert` on all siblings of `#dialog-root` (app root), (c) set `inert` on ALL previously-stacked dialog containers (so only the topmost is interactive)
- `popDialog`: (a) remove element from stack, (b) remove `inert` from the new topmost dialog (if any), (c) remove `inert` from app siblings ONLY if stack is now empty
- `isTopmost`: return whether element is the last in the stack
- React hook: `useDialogStack()` returns `{ stackSize: number }` for components that need to react to stack changes
- Use `element.setAttribute('inert', '')` / `element.removeAttribute('inert')` — React does NOT support `inert` as a prop
- Follow existing utility patterns in `src/utils/`

## Key context

- React does NOT allow setting `inert` as a React prop — must use ref with `setAttribute`/`removeAttribute`
- Existing portal pattern: `src/App.tsx:568` (Toast), `src/components/common/Select.tsx:571`
- Existing hooks export from `src/hooks/index.ts`

## Done summary
Created useFocusTrap hook and dialogStack utility.

useFocusTrap:
- Traps Tab/Shift+Tab within container ref
- Re-queries focusable elements on every Tab keypress (handles dynamic content)
- Comprehensive focusable selector covering all interactive elements
- Excludes elements inside [inert] and [aria-hidden="true"] subtrees
- enabled option to conditionally disable the trap
- Attaches keydown listener to container element, cleans up on unmount

dialogStack:
- Module-level stack tracking open dialog container elements
- pushDialog: adds element, sets inert on app root siblings + all previously-stacked dialog containers
- popDialog: removes element, restores inert on new topmost dialog, removes app inert only when stack empty
- isTopmost: checks if element is the topmost dialog

Both modules exported from their respective index files. pnpm tsc --noEmit passes.
