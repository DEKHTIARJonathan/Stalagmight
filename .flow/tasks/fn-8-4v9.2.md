# fn-8-4v9.2 Add setActiveTool to SurveyLayer and disable hover for non-interactive tools

## Description
Add setActiveTool method to SurveyLayer and disable hover effects for non-interactive tools.

## Implementation

### 1. Add activeTool property and setActiveTool method

**CRITICAL**: Also call callbacks to clear MapCanvas's isHoveringFeature state.

```typescript
import { NON_INTERACTIVE_TOOLS, ToolType } from '../../store/uiStore';

private activeTool: ToolType = 'select';

public setActiveTool(tool: ToolType): void {
  const wasNonInteractive = NON_INTERACTIVE_TOOLS.includes(this.activeTool);
  const isNonInteractive = NON_INTERACTIVE_TOOLS.includes(tool);
  
  this.activeTool = tool;
  
  // Clear hover when switching to non-interactive tool
  if (!wasNonInteractive && isNonInteractive) {
    this.hoveredStationId = null;
    this.hoveredShotId = null;
    this.updateVisualState();
    this.map.getCanvas().style.cursor = '';
    
    // CRITICAL: Also notify callbacks to clear MapCanvas state
    this.callbacks.onFeatureHover?.(false);
    this.callbacks.onStationHover?.(null);
    this.callbacks.onShotHover?.(null);
  }
}
```

### 2. Update mouseenter handlers

Add early return check at start of each mouseenter handler:

```typescript
this.map.on('mouseenter', this.stationsLayerId, (e) => {
  if (NON_INTERACTIVE_TOOLS.includes(this.activeTool)) return;
  // ... existing logic
});

this.map.on('mouseenter', this.shotsLayerId, (e) => {
  if (NON_INTERACTIVE_TOOLS.includes(this.activeTool)) return;
  // ... existing logic
});
```

### 3. Don't change cursor to pointer for non-interactive tools

The mouseenter early return prevents cursor change naturally.
