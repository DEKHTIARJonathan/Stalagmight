# Task: Integrate focus trap into DialogWrapper

## Description

Wire the `useFocusTrap` hook into `DialogWrapper.tsx` for both the main dialog and the nested dirty-confirm alertdialog.

### Requirements

1. **Main dialog trap**: Add a `ref` to the main dialog `<div role="dialog">` and pass it to `useFocusTrap`. Active whenever the dialog is mounted.
2. **Nested alertdialog trap**: When `showConfirm` is true, add a second `useFocusTrap` on the `<div role="alertdialog">` container.
3. **Pause outer trap**: When the alertdialog opens, pause the outer dialog's focus trap. Add `inert` attribute to the outer dialog panel so its contents are not reachable by assistive technology.
4. **Resume outer trap**: When the alertdialog closes (Cancel or Discard), resume the outer dialog's focus trap and remove `inert`.
5. **No interference with Escape**: The existing Escape key handler must continue to work correctly — the focus trap only intercepts Tab/Shift+Tab.

### Files to modify

- `src/components/Dialogs/DialogWrapper.tsx`

## Acceptance Criteria

- [ ] Tab cannot escape the main dialog when it is open.
- [ ] Tab cannot escape the alertdialog when it is open.
- [ ] Outer dialog gets `inert` attribute when alertdialog is shown.
- [ ] Outer dialog loses `inert` and trap resumes when alertdialog is dismissed.
- [ ] Escape key still works to close dialog / dismiss alertdialog.
- [ ] `pnpm tsc --noEmit` passes.
