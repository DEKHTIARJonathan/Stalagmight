## Description

Add Playwright e2e tests covering section dropdown hover highlighting: mouse hover triggers map highlight, keyboard navigation (ArrowDown, ArrowUp, Home, End) triggers map highlight, Tab closes and clears highlight, trigger-toggle-to-close clears highlight, and all close paths clear map highlight (8 close paths total: handleSelect, outside-click, Escape, Tab, trigger-toggle-to-close, component unmount, scroll, resize).

**Size:** M
**Files:**
- `e2e-playwright/section-dropdown-hover.spec.ts` (new test file)
- `docs/TESTING.md` (add Select hover test patterns)

## Approach

### Test file

Create `e2e-playwright/section-dropdown-hover.spec.ts` following patterns from `section-highlighting.spec.ts` and `detail-link-hover.spec.ts`.

- Use `setupMockedPage(page)` / `setupTauriMocks(page)` + `createProject(page)` fixtures
- Use `waitForMapReady(page)` before assertions
- Use `triggerMouseHover()` pattern from `detail-link-hover.spec.ts:272-282` if `page.hover()` is unreliable for React onMouseEnter
- Use `page.evaluate()` to read `hoveredSectionId` from uiStore
- Use `expect.poll()` for async state verification

### Test describe structure

Use `test.describe('Section dropdown hover highlighting', ...)` so the grep pattern `"section dropdown hover"` matches.

### Test cases

1. **Mouse hover -> map highlight**: Open section dropdown, hover an option via `page.hover()` or `triggerMouseHover()`, verify `hoveredSectionId` in uiStore matches the hovered section.

2. **ArrowDown keyboard nav -> map highlight**: Open section dropdown, press ArrowDown, verify `hoveredSectionId` updates. Press ArrowDown again, verify it changes to next section.

3. **ArrowUp keyboard nav -> map highlight**: With dropdown open and an option highlighted, press ArrowUp, verify `hoveredSectionId` updates to previous section.

4. **Home/End keyboard nav -> map highlight**: With dropdown open, press End to jump to last option, verify `hoveredSectionId`. Press Home to jump to first, verify.

5. **Escape closes and clears highlight**: Open dropdown, hover an option (verify highlight set), press Escape, verify `hoveredSectionId` is null and dropdown is closed.

6. **Click outside closes and clears**: Open dropdown, hover an option, click outside, verify `hoveredSectionId` is null.

7. **Select option closes and clears**: Open dropdown, hover an option, click to select it, verify `hoveredSectionId` is null after selection.

8. **Tab closes and clears**: Open dropdown, hover an option, press Tab, verify `hoveredSectionId` is null.

9. **Trigger-toggle-to-close clears**: Open dropdown, hover an option, click trigger button again, verify `hoveredSectionId` is null.

10. **External scroll closes and clears**: Open dropdown, hover an option (verify highlight set), trigger a scroll event on a parent element (not the dropdown itself), verify `hoveredSectionId` is null and dropdown is closed. Note: the implementation ignores scroll events inside the portaled dropdown (`dropdownRef.current?.contains(event.target)` guard) so the test must scroll an external element.

11. **Window resize closes and clears**: Open dropdown, hover an option (verify highlight set), trigger a `resize` event on the window, verify `hoveredSectionId` is null and dropdown is closed.

## Key context

- **Playwright hover() unreliable for React onMouseEnter**: Use `triggerMouseHover()` pattern from `detail-link-hover.spec.ts:272-282` which dispatches `mouseover` with `bubbles: true`.
- **React onMouseEnter/Leave**: Requires dispatching `mouseover`/`mouseout` with `bubbles: true`, not `mouseenter`/`mouseleave` (project memory pitfall).
- **State polling**: Use `expect.poll()` for async state changes, following `section-highlighting.spec.ts` patterns.
- **Test grep**: Describe block must include "section dropdown hover" to match `pnpm test:ui -- --grep "section dropdown hover"`.
