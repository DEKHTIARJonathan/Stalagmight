# fn-11-6w4.7 Extend ExportPreview to display depth colors

## Description
Extend ExportPreview component to display depth colors when color mode is depth.

**Depends on:** fn-11-6w4.6 (ExportDialog with color mode props)

## Props Update

```typescript
interface ExportPreviewProps {
  options: ExportImageOptions;
  theme: ExportTheme;
  colorMode: ColorMode;
  depthPreset?: DepthPreset;
  presetColors?: { shallow: string; deep: string } | null;
}
```

## Use getDepthColor from colors.ts

The frontend already has `getDepthColor` in `src/utils/colors.ts` (from fn-5-jef). Use it for preview coloring.

```typescript
import { getDepthColor } from '../../utils/colors';

// In updatePreview callback
const stationFeatures: GeoJSON.Feature[] = stations.map((station) => {
  const section = sections.find((s) => s.id === station.station_ref.section_id);
  
  let color: string;
  if (station.is_zero_datum) {
    color = '#ffd700'; // Gold for zero datum always
  } else if (colorMode === 'depth' && presetColors) {
    color = getDepthColor(
      station.coordinates.z,
      presetColors.shallow,
      presetColors.deep,
      depthRange.min,
      depthRange.max
    ) ?? section?.color ?? '#ffffff';
  } else {
    color = section?.color ?? '#ffffff';
  }
  
  return {
    type: 'Feature',
    geometry: {
      type: 'Point',
      coordinates: metersToMapCoords(station.coordinates.x, station.coordinates.y),
    },
    properties: {
      sectionId: station.station_ref.section_id,
      stationIndex: station.station_ref.station_index,
      isZeroDatum: station.is_zero_datum,
      color,
    },
  };
});
```

## Calculate Depth Range

```typescript
// Calculate depth range for gradient
const depthRange = useMemo(() => {
  if (colorMode !== 'depth' || !stations.length) {
    return { min: 0, max: 50 };
  }
  const depths = stations.map(s => s.coordinates.z);
  return {
    min: Math.min(...depths),
    max: Math.max(...depths),
  };
}, [stations, colorMode]);
```

## Shot Colors

Similarly update shot features to use depth colors:
```typescript
const avgDepth = (fromStation.coordinates.z + toStation.coordinates.z) / 2;
const color = colorMode === 'depth' && presetColors

    ?? section.color
  : section.color;
```
