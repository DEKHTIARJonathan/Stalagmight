# fn-13-e55.4 Create ShortcutRecorder component with key capture

## Description
Create ShortcutRecorder component for capturing keyboard input. Shows recording state, handles Escape to cancel, displays keyboard-style badges.

**Size:** M
**Files:** `src/components/Settings/ShortcutRecorder.tsx`, `src/components/Settings/__tests__/ShortcutRecorder.test.tsx`

## Approach

- Similar to react-hotkeys-hook `useRecordHotkeys` pattern (github-scout)
- Click to enter recording mode, keydown captures combo, keyup completes
- Use utilities from fn-13-e55.3 for normalization and display
- Follow existing component patterns

## Key context

- Blocked keys: F1-F12, Tab, Caps Lock, Meta (OS key)
- Escape cancels recording, restores previous value
- Show "Click to record" placeholder when empty
- Keyboard badge styling: subtle rounded bg, border
- ARIA: role="button", aria-pressed for recording state, aria-live for announcements
