**Current state:**
- SVG/PDF export works via Rust backend (`src-tauri/src/export/image.rs`)
- PNG export fails with "PNG export requires frontend rendering"
- No color mode option in export dialog
- No progress indicator for exports
- ExportPreview component shows section colors only

**Multi-stop interpolation (used by both backend and frontend):**
```rust
pub fn get_depth_color(depth: f64, min_depth: f64, max_depth: f64, preset: DepthPreset) -> String {
    // CRITICAL: Check for NaN/infinite
    if !depth.is_finite() || !min_depth.is_finite() || !max_depth.is_finite() {
        return preset.colors().stops[0].color.clone();
    }
    
    if (max_depth - min_depth).abs() < f64::EPSILON {
        return preset.colors().stops[0].color.clone();
    }
    
    let t = ((depth - min_depth) / (max_depth - min_depth)).clamp(0.0, 1.0);
    interpolate_stops(t, &preset.colors().stops)
}

fn interpolate_stops(t: f64, stops: &[ColorStop]) -> String {
    // Find bracketing stops
    for i in 0..stops.len() - 1 {
        if t >= stops[i].position && t <= stops[i + 1].position {
            let local_t = (t - stops[i].position) / (stops[i + 1].position - stops[i].position);
            return interpolate_rgb(&stops[i].color, &stops[i + 1].color, local_t);
        }
    }
    stops.last().unwrap().color.clone()
}
```

### 5. Depth Legend SVG Element
**CRITICAL: Use viewBox-relative units. Account for Y-axis flip.**

Legend positioned in **viewBox coordinates** (pre-flip). The SVG already flips Y with negative values, so legend uses `-(bounds.max_y - padding)` for Y position.

**Unit conversion for legend labels:**
```rust
fn format_depth_label(depth: f64, unit: &str, precision: u8) -> String {
    let value = if unit == "ft" {
        depth * 3.28084  // meters to feet conversion
    } else {
        depth
    };
    format!("{:.prec$}{}", value, unit, prec = precision as usize)
}
```

## Edge Cases

| Case | Handling |
|------|----------|
| All stations at same depth | All get first stop color, legend shows "X.Xm (Flat)" |
| min === max | t=0, returns first stop color |
| z < min | Clamp t to 0 |
| z > max | Clamp t to 1 |
| NaN/infinite z | **Explicit is_finite() check**, returns first stop color |
| Invalid preset | **Error** - Rust enum fails deserialization |
| Export size > 16384px | **Error** with clear message |
| Export cancelled | **Not supported** - sync command |
| Unit = "ft" | **Convert value** (meters * 3.28084), not just suffix |
