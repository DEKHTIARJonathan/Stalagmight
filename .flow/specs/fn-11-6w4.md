# Export System Enhancement

## Problem

The export dialog lacks color mode options. Users cannot export maps with depth gradient coloring - exports always use section colors. Additionally, PNG export is broken (backend bails with error), and there's no visual feedback during export.

**Current state:**
- SVG/PDF export works via Rust backend (`src-tauri/src/export/image.rs`)
- PNG export fails with "PNG export requires frontend rendering"
- No color mode option in export dialog
- No progress indicator for exports
- ExportPreview component shows section colors only

## Dependencies

**Hard dependencies (must complete first):**
- `fn-10-i64`: Loading Progress Indicator (for export progress UI)
- `fn-5-jef`: Depth Gradient Display (for `getDepthColor` HSL interpolation)

## Scope

**In Scope:**
- Add color mode dropdown (section colors vs depth gradient)
- Add depth color preset selector (thermal, ocean, terrain, grayscale, accessible)
- Fix PNG export via resvg rasterization
- Add depth legend option for exports
- Add 600 DPI option for PNG
- Extend ExportPreview to show depth colors
- Progress indicator during export (using fn-10-i64 infrastructure)
- Comprehensive tests (Rust unit, TypeScript unit, Playwright E2E, WebdriverIO)

**Out of Scope:**
- Viewport region selection (always exports full project extent)
- Batch export (one format at a time)
- Custom color pickers (use presets only)

### 3. PNG Rasterization with resvg
Add `resvg` dependency to `Cargo.toml`:
```toml
resvg = "0.44"
```

Update `export_image()` in `image.rs`:
```rust
ImageFormat::Png => {
    // Generate SVG first
    let svg_content = generate_svg_string(project, options)?;
    
    // Parse and render with resvg
    let tree = usvg::Tree::from_str(&svg_content, &usvg::Options::default())?;
    let pixmap_size = tree.size().to_int_size();
    let scale = options.dpi as f32 / 72.0;
    
    let mut pixmap = tiny_skia::Pixmap::new(
        (pixmap_size.width() as f32 * scale) as u32,
        (pixmap_size.height() as f32 * scale) as u32,
    ).ok_or("Failed to create pixmap")?;
    
    resvg::render(&tree, tiny_skia::Transform::from_scale(scale, scale), &mut pixmap.as_mut());
    pixmap.save_png(path)?;
}
```

## Edge Cases

| Case | Handling |
|------|----------|
| All stations at same depth | Legend shows "X.Xm (Flat)", solid color |
| No depth data (all z=0) | Depth mode still works, shows all shallow color |
| Very large project | Progress indicator shows station count |
| Export cancelled | Clean up partial file |
| Invalid preset | Default to Thermal |
