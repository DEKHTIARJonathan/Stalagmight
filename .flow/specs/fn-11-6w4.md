### 1. Rust Depth Color Module
New file: `src-tauri/src/export/depth_colors.rs`

**Depth color presets with multi-stop gradients:**
```rust
pub enum DepthPreset {
    Thermal,    // Multi-stop: Blue → Cyan → Green → Yellow → Red
    Ocean,      // Two-stop: Cyan (#00ffff) → Dark Blue (#0000aa)
    Terrain,    // Two-stop: Green (#00ff00) → Brown (#8b4513)
    Grayscale,  // Two-stop: White (#ffffff) → Black (#000000)
    Accessible, // Two-stop: Purple (#7c3aed) → Yellow (#fde047) - Viridis-inspired (dark to light)
}
```

**CRITICAL: Thermal uses multi-stop interpolation, NOT two-point HSL:**
```rust
// Thermal preset: explicit color stops for rainbow spectrum
const THERMAL_STOPS: &[(f64, &str)] = &[
    (0.0, "#00bfff"),  // Shallow: Blue
    (0.25, "#00ffaa"), // Cyan-green
    (0.5, "#44ff00"),  // Green
    (0.75, "#ffff00"), // Yellow
    (1.0, "#ff4444"),  // Deep: Red
];

pub fn get_depth_color(depth: f64, min_depth: f64, max_depth: f64, preset: DepthPreset) -> String {
    // Clamp t to [0, 1]
    let t = if (max_depth - min_depth).abs() < f64::EPSILON {
        0.0 // All same depth -> shallow color
    } else {
        ((depth - min_depth) / (max_depth - min_depth)).clamp(0.0, 1.0)
    };
    
    match preset {
        DepthPreset::Thermal => interpolate_multi_stop(t, THERMAL_STOPS),
        _ => interpolate_two_point(t, &preset.colors()),
    }
}
```

**Tauri command for preset colors:**
```rust
#[tauri::command]

}
```

**CRITICAL: Fix scaling and add size limits:**
```rust
fn export_png(project: &Project, path: &Path, options: &ExportImageOptions) -> Result<()> {
    let svg_content = generate_svg_string(project, options)?;
    
    let opt = usvg::Options::default();
    let tree = usvg::Tree::from_str(&svg_content, &opt)?;
    
    // Calculate size with DPI scaling
    let size = tree.size();
    let scale = options.dpi as f32 / 72.0;
    let width = (size.width() * scale) as u32;
    let height = (size.height() * scale) as u32;
    
    // CRITICAL: Hard limit to prevent OOM
    const MAX_DIMENSION: u32 = 16384;
    if width > MAX_DIMENSION || height > MAX_DIMENSION {
        anyhow::bail!(
            "Export size {}x{} exceeds maximum {}px. Reduce DPI or use SVG format.",
            width, height, MAX_DIMENSION
        );
    }
    
    let mut pixmap = tiny_skia::Pixmap::new(width, height)
        .ok_or_else(|| anyhow::anyhow!("Failed to create pixmap"))?;
    
    // Correct API for resvg 0.43
    resvg::render(&tree, tiny_skia::Transform::from_scale(scale, scale), &mut pixmap.as_mut());
    
    pixmap.save_png(path)?;
    Ok(())
}
```

**CRITICAL: Fix SVG sizing to allow scale-down:**
```rust
// In generate_svg_string(), remove .max(1.0) that prevents downscaling:
```

### 7. Extend ExportPreview Component
**Extract pure function for color computation (testable):**
```typescript
// src/utils/export-colors.ts - NEW FILE
export function computeStationColor(
  station: Station,
  section: Section | undefined,
  colorMode: ColorMode,
  depthRange: { min: number; max: number },
  presetColors: { shallow: string; deep: string } | null,
): string {
  if (station.is_zero_datum) {
    return '#ffd700'; // Gold always
  }
  
  if (colorMode === 'depth' && presetColors) {
    return getDepthColor(
      station.coordinates.z,
      presetColors.shallow,
      presetColors.deep,
      depthRange.min,
      depthRange.max
    ) ?? section?.color ?? '#ffffff';
  }
  
  return section?.color ?? '#ffffff';
}
```

## Edge Cases

| Case | Handling |
|------|----------|
| All stations at same depth | All get shallow color, legend shows "X.Xm (Flat)" |
| min === max | `get_depth_color` returns shallow color (t=0) |
| z < min | Clamp to shallow color |
| z > max | Clamp to deep color |
| NaN/undefined z | Return shallow color |
| Invalid preset | **Error** - Rust enum fails deserialization, frontend validates |
| Export size > 16384px | **Error** with clear message suggesting SVG or lower DPI |
| Export cancelled | **Not supported** - sync command, no cancellation |
