# Configurable Keyboard Shortcuts System

## Problem

Keyboard shortcuts are hardcoded in `useKeyboardShortcuts.ts`. Users need configurable shortcuts with:
- Two key bindings per action (primary + secondary)
- Settings UI for visual configuration
- Conflict detection and resolution

**Blocked task**: `fn-5-jef.7` waiting for this infrastructure.

## Scope

**Configurable actions by category:**

| Category | Actions |
|----------|---------|
| Tools | select, pan, zoom, quick_zoom (spring-loaded), draw, delete_tool, merge, measure, move_section, move_station |
| Edit | undo, redo, save |
| View | toggle_depth_gradient, toggle_grid, toggle_satellite, toggle_station_labels, toggle_shot_labels, toggle_section_labels, fit_to_bounds, zoom_in, zoom_out |
| Panels | toggle_sections_panel, toggle_detail_panel, toggle_data_table |

**Reserved shortcuts (NOT configurable):**
- Escape: Always close dialogs, clear selection
- Delete/Backspace: Delete selected item (with confirmation)
- Ctrl+I: Import DMP
- Ctrl+E: Export
- Ctrl+A: Select all stations

These are shown in UI as "Reserved" and blocked from conflict assignment.

## Key Decisions

### Config Format
- Array of strings per action: `["S", "Shift+S"]` (max 2)
- **Backward-compatible deserialization**: Use `#[serde(deserialize_with)]` to accept both legacy single `String` and new `Vec<String>` format
- **`#[serde(default)]` on ShortcutsConfig struct** to handle missing fields in existing configs
- Migration: `normalize()` merges defaults for missing fields

### Validation & Canonicalization
- **Normalization rules**:
  1. Lowercase key names (except modifiers)
  2. Sort modifiers: Ctrl → Alt → Shift → Key
  3. Platform aliases: "Meta" → "Ctrl" on Windows/Linux
  4. Truncate arrays > 2 elements
- **Special key canonical names**: `Space`, `Enter`, `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`, `Plus`, `Minus`, `Equal`
- **Conflict detection**: Compare normalized shortcuts; reserved shortcuts are blocked
- **Invalid format**: Fall back to default for that action with warning log

### Zoom In/Out Implementation
- `zoom_in`: Calls `map.zoomTo(currentZoom + config.map.zoom_step)` via global map ref
- `zoom_out`: Calls `map.zoomTo(currentZoom - config.map.zoom_step)` via global map ref
- Default bindings: `=`/`+` for zoom in, `-` for zoom out
- Respects `zoom_min`/`zoom_max` from config

### Spring-Loaded Behavior
- `quick_zoom` uses spring-loaded (keydown activates, keyup restores)
- Only non-modifier keys (e.g., "Z" alone, not "Shift+Z")
- `zoom` is regular toggle behavior

### Input Element Guards
- **Preserve existing behavior**: Ignore all shortcuts (except Escape) when focus is in input/textarea/select
- Escape always works for dialog close and state reset

### Toast Feedback Config
- New config field: `general.shortcut_feedback` with enum: `"none"` | `"non_obvious"` | `"all"`
- Default: `"non_obvious"`
- Non-obvious: View/Panel toggles show toast
- All: All shortcuts show toast
