# Enrich ProjectMetadata with GPS info

## Overview
Add GPS center/bounds from zero datums. Needed by fn-20, fn-21.

## Scope
- gps_center: Option<(f64, f64)> from first zero datum
- gps_bounds: Option<GpsBounds>
- None for projects without GPS

## Quick commands
```bash
cd src-tauri && cargo test
```

## Acceptance
- [ ] GPS fields added
- [ ] Center from first zero datum
- [ ] Bounds include all datums
