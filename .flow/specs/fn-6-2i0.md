# Add comment column to DMP Import Dialog

## Overview

Add comment field to DmpShot and display expandable comment column in shot preview table. Comments are user-entered notes per shot.

## Dependencies

**Requires fn-4-qe3** - expandable shot preview table must exist first.

## Scope

- Add `comment` field to Rust DmpShot struct and TypeScript interface
- Update DMP parser to extract comments (if format supports)
- Add Comment column with truncated view + expand on click
- Keyboard accessible (Tab, Enter to expand)
- WCAG 2.1 AA compliant

### Out of Scope
- Editing comments in preview
- Tooltip-only display

## Approach

### Task 1: Add comment field to DmpShot
1. Add `comment: Option<String>` to Rust `DmpShot` in `dmp.rs`
2. Update parser to extract comment from DMP format
3. Add `comment?: string` to TypeScript `DmpShot` interface

### Task 2: Add comment column UI
1. Add Comment column after Pitch column
2. Truncate at ~50 chars with "..." when collapsed
3. Show expand icon when truncated
4. Click row/icon to expand full comment
5. Add aria-expanded, keyboard navigation
