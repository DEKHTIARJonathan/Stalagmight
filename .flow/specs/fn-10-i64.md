# Loading Progress Indicator

## Problem

When loading a project, the UI currently displays only a simple "Loading..." text with no indication of:
- What operation is currently happening
- How much progress has been made  
- How long the user might need to wait
- Whether any errors occurred

This is especially problematic for larger projects where loading can take noticeable time, leaving users uncertain about application state.

## Approach

### 1. Visual Design

**Location**: Centered in screen (same position as current "Loading...")

**Layout**: Compact card (~300-400px wide) containing:
- Project name at top ("Loading ProjectName...")
- Overall progress bar (weighted by phase)
- Current phase text (e.g., "Step 3/8: Calculating positions...")
- Per-phase progress bar (determinate or indeterminate)
- Item counts where applicable (e.g., "23/50 stations")
- Cancel button below progress bars

**Style**:
- Subtle/minimal design using theme colors (accent color for bars)
- Thin progress bars, muted colors
- Subtle pulse animation using Tailwind's `animate-pulse` + `motion-safe:`
- Smooth CSS transitions for progress updates (duration-300)
- Modal behavior (blocks other interactions)

### 2. Consolidated Load Pipeline

**Single In-Flight Load Constraint**: Only one load at a time. Frontend ALWAYS calls `cancel_loading` (unconditionally) before starting new load. Backend cancel is idempotent.

**Atomic State Mutation**: All results computed locally first. AppState ONLY mutated at end, with cancel checks before EACH mutation.

### 3. Backend Architecture

**AppState Ownership for spawn_blocking**:
```rust
// State<T> in Tauri is Clone (it wraps Arc internally).
// The HANDLE is cloned, not the data. This is the correct pattern.

#[tauri::command]
pub async fn load_project_full(
    path: String,
    state: State<'_, AppState>,
) -> Result<LoadProjectFullResult, LoadError> {
    // Clone the State handle (cheap, just Arc clone)
    let state = state.clone();

    // Move the cloned handle into spawn_blocking
    let result = tokio::task::spawn_blocking(move || {
        // state is now owned by this closure, can use it freely
        do_load_project_full(&state, path)
    }).await.map_err(|e| LoadError::internal(e.to_string()))??;

    Ok(result)
}

// Alternative: if State<T> clone doesn't work in this Tauri version,
// wrap AppState fields in Arc and pass those directly.
// But State<T>::clone() is the documented Tauri pattern.
```

**Idempotent cancel_loading**:
```rust
#[tauri::command]
pub fn cancel_loading(state: State<AppState>) {
    // Safe to call anytime, even when no load active
    if let Some(token) = state.active_loading.lock().unwrap().as_ref() {
        token.store(true, Ordering::SeqCst);
    }
    // No error if active_loading is None
}
```
