# Loading Progress Indicator

## Problem

When loading a project, the UI currently displays only a simple "Loading..." text with no indication of:
- What operation is currently happening
- How much progress has been made  
- How long the user might need to wait
- Whether any errors occurred

This is especially problematic for larger projects where loading can take noticeable time, leaving users uncertain about application state.

## Approach

### 1. Visual Design

**Location**: Centered in screen (same position as current "Loading...")

**Layout**: Compact card (~300-400px wide) containing:
- Project name at top ("Loading ProjectName...")
- Overall progress bar (weighted by phase)
- Current phase text (e.g., "Step 3/8: Calculating positions...")
- Per-phase progress bar (determinate or indeterminate)
- Item counts where applicable (e.g., "23/50 stations")
- Cancel button below progress bars

**Style**:
- Subtle/minimal design using theme colors (accent color for bars)
- Thin progress bars, muted colors
- Subtle pulse animation using Tailwind's `animate-pulse` + `motion-safe:`
- Smooth CSS transitions for progress updates (duration-300)
- Modal behavior (blocks other interactions)

### 2. Consolidated Load Pipeline

**Single In-Flight Load Constraint**: Only one load can be active at a time. Frontend explicitly calls `cancel_loading` before starting a new load. Backend `cancel_loading` is idempotent (safe to call when no load active).

**Atomic State Mutation**: All results are computed locally first. AppState is ONLY mutated at the very end, with cancel checks before EACH mutation.

**8 Phases**:
1. Opening database (5%)
2. Loading project data (20%) - 1 unit
3. Loading sections (15%) - N sections
4. Computing stations (20%) - Adds optional callback to existing `compute_station_coordinates`
5. Computing statistics (15%) - N sections (coarse-grained, section-level)
6. Validating data (10%) - 1 unit
7. Loading settings (5%) - 1 unit
8. Finalizing (10%) - 1 unit, cancel checks before EACH mutation

**Atomic State Mutation** (cancel checks before EACH mutation):
```rust
// === PHASE 7: Finalizing (10%) ===
progress.start_phase(LoadingPhase::Finalizing);

// Cancel check before EACH mutation
if progress.is_cancelled() { self.clear_active_load(); return Err(LoadError::cancelled()); }
*self.project.lock().unwrap() = Some(project.clone());

if progress.is_cancelled() { self.clear_active_load(); return Err(LoadError::cancelled()); }
self.add_to_recent(&path)?;

progress.complete_phase(LoadingPhase::Finalizing);
self.clear_active_load();
```

**Idempotent cancel_loading**:
```rust
#[tauri::command]
pub fn cancel_loading(state: State<AppState>) {
    // Safe to call when no load active
    if let Some(token) = state.active_loading.lock().unwrap().as_ref() {
        token.store(true, Ordering::SeqCst);
    }
}
```

**Error Type** (guaranteed JSON):
```rust
impl std::fmt::Display for LoadError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match serde_json::to_string(self) {
            Ok(json) => write!(f, "{}", json),
            Err(_) => write!(f, "{{\"code\":\"{}\",\"message\":\"{}\"}}", 
                self.code, self.message.replace('\"', "\\\""))
        }
    }
}
```

### 4. Event Payload

```rust
#[derive(Clone, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct LoadingProgress {
    pub loading_id: u64,
    pub phase: LoadingPhase,
    pub phase_index: u8,
    pub phase_count: u8,
    pub current: Option<u32>,
    pub total: Option<u32>,
    pub overall_percent: f32,
    pub is_indeterminate: bool,
}
```

**Event name**: `loading-progress`

**Heartbeat**: Every 2s during indeterminate phases.

**Throttling**: Every 10 items or 50ms during granular phases, always at 0% and 100%.

loadProject: async (path: string) => {
  // ALWAYS cancel first (idempotent on backend)
  if (get().loading.isLoading) {
    await get().cancelLoading();
  }
  
  const initialName = path.split('/').pop()?.replace(/\.(cvproj|cvchef)$/, '') ?? 'Project';
  const loadingId = get().startLoading(initialName, path);
  
  try {
    const result = await invoke<LoadProjectFullResult>('load_project_full', { path });

  } catch (e) {

  }
},
