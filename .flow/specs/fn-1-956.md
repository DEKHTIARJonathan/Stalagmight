**Problem**: Escape key doesn't close dialogs

**Solution**: Update `useKeyboardShortcuts.ts` with dialog-aware Escape handling:

- No dialog + not in input → Clear tools (existing behavior)
- Use `event.preventDefault()` when closing dialog

See `.flow/specs/fn-3-m4h.md` for full details.
