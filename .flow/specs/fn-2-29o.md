# Fix: "should display section name input field" Test

## Problem

The WebdriverIO test fails because it tests the wrong dialog.

## Root Cause

The test calls `openImportDialog()` which triggers `Ctrl+I`, opening **DmpImportDialog**. But the section name input is in **ImportDialog** (different component).

## Solution

### Component Changes

1. **ImportDialog.tsx**: Add `data-testid="section-name-input"` and `data-testid="import-section-dialog"`
2. **DmpImportDialog.tsx**: Add `data-testid="import-dmp-dialog"`

### Test Changes

1. **Rename, REWRITE, and REMOVE old spec**:
   - REMOVE `import-dialog.spec.ts`
   - CREATE `import-dmp-dialog.spec.ts` (rewritten for DmpImportDialog)
   - CREATE `import-section-dialog.spec.ts` for ImportDialog tests

2. **Use data-testid selectors consistently**:
   - All tests MUST use `[data-testid="import-section-dialog"]` or `[data-testid="import-dmp-dialog"]`
   - Avoid `[role="dialog"]` alone (can match any dialog)

3. **UI-path test (via "+" button)**:
   - Use store state to EXPLICITLY SET `sectionsPanelOpen = true` first
   - Don't use Ctrl+1 toggle (unreliable - toggles)
   - Then click "+" button

### Helper Fixes - Error-Safe executeAsync

**`resetAppState()` - With error handling:**

```typescript
export async function resetAppState(): Promise<void> {
  // First ensure E2E helpers available
  await browser.waitUntil(
    async () => await browser.execute(() => !!(window as any).__E2E_TEST__),
    { timeout: 5000, timeoutMsg: 'E2E helpers not available' }
  );

  // Use executeAsync with error handling
  const result = await browser.executeAsync((done) => {
    const e2e = (window as any).__E2E_TEST__;
    if (!e2e) {
      done({ ok: false, error: 'E2E helpers not found' });
      return;
    }
    
    (async () => {
      try {
        e2e.uiStore.getState().closeDialog();
        await e2e.projectStore.getState().closeProject();
        e2e.uiStore.getState().setView('global');
        done({ ok: true });
      } catch (err) {
        done({ ok: false, error: String(err) });
      }
    })();
  });

  // Check result and throw if failed
  if (!result.ok) {
    throw new Error(`resetAppState failed: ${result.error}`);
  }

  // Verify project is closed
  await browser.waitUntil(
    async () => await browser.execute(() => {
      const e2e = (window as any).__E2E_TEST__;
      return e2e && e2e.projectStore.getState().project === null;
    }),
    { timeout: 5000, timeoutMsg: 'Project did not close' }
  );

  // Wait for GlobalView
  const globalView = await $('[data-testid="global-view"]');
  await globalView.waitForExist({ timeout: 5000 });
}
```

**UI-path test helper:**

```typescript
// Ensure Sections panel is open (don't toggle - set explicitly)
async function ensureSectionsPanelOpen(): Promise<void> {
  await browser.execute(() => {
    const e2e = (window as any).__E2E_TEST__;
    if (e2e) {
      e2e.uiStore.getState().setSectionsPanelOpen(true);
    }
  });
  await browser.pause(100); // Let React render
}
```
