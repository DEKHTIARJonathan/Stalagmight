# Satellite Map Tile Caching

## Problem

CaveChef users need offline access to satellite imagery for cave survey work in remote locations without internet. Currently, satellite tiles are fetched live from ESRI with no caching, making offline work impossible.

## Approach

### Architecture (Finalized after 3 Codex Reviews)

1. **Backend**: `TileCacheManager` struct in `src-tauri/src/cache/mod.rs` managing SQLite DB
2. **Tile Fetching**: Tauri command `fetch_tile` with `ureq` + `spawn_blocking`
3. **Frontend**: MapLibre `addProtocol('cavechef-tiles', ...)` on main thread (raster tiles only)
4. **Status API**: Single `get_cache_status` endpoint for offline/disk/stats

**Protocol Flow** (raster tiles use main thread):
```
MapLibre RasterSource → addProtocol('cavechef-tiles') [main thread]
    ↓
invoke('fetch_tile', {provider: 'esri', z, x, y})
    ↓
Tauri Command (spawn_blocking):
    - Check backpressure (>16? cooldown check → stale or fail)
    - Check dedup map (in-flight? wait)
    - Cache hit → return bytes
    - Cache miss → fetch via ureq → cache → return
```

### Key Decisions

**Cache Storage**:
- 500MB logical bytes limit (evict loop until space available)
- SQLite with `PRAGMA auto_vacuum = INCREMENTAL`
- DB at `{app_data_dir}/tile_cache.db`
- Integrity check on startup, recreate if corrupt

**Request Handling**:
- Backpressure: 16 pending max, 2s cooldown per-tile on error
- Soft error returns transparent tile (prevents MapLibre retry storm)
- Request dedup via InFlightMap with waiter_count
- 60s safety backstop for orphaned entries

**Tile States**:
- Fresh (<30 days): Serve immediately
- Stale (>=30 days): Serve + queue background refresh
- Refresh uses same dedup map (skip if in-flight)

**Content Validation**:
- MIME: image/jpeg, image/jpg, image/png
- Magic bytes fallback: JPEG (FF D8 FF) or PNG (89 50 4E 47)
- Zero-byte: Cache as valid "no data" marker

**Status Polling**:
- Single `get_cache_status` API returns: tile_count, cache_bytes, disk_available, is_offline, is_low_disk
- Frontend polls every 10s + on Settings tab open

**Config**:
- `CacheConfig` with `#[serde(default)]` for migration
- UI updates via existing `update_config` pattern

### Settings UI
- Location: GlobalView → Settings button → SettingsDialog → Storage tab
- Stats: Tile count + MB, clear button, cache config
