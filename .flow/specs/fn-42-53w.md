# Playwright E2E: Error Handling

## Overview
Implement Playwright E2E tests for error handling scenarios. These tests validate that errors are communicated clearly to users and the app remains functional after errors.

## Scope
- Target: `e2e-playwright/error-handling.spec.ts` (new file)
- Category: Playwright E2E Tests
- Tests: 6
- Priority: P1 - High
- Dependencies: task-06 (project creation helpers)

## Approach
1. Create test file for error handling
2. Update tauri-ipc.ts mocks to support error simulation
3. Test save errors (permission denied, disk full)
4. Test file open errors (corrupted, not found)
5. Test DMP parse errors
6. Test network/IPC timeout handling
7. Test form validation errors
8. Test undo/redo error recovery

- `pnpm test:ui --grep "Error Handling"`
- `pnpm test:ui:headed --grep "Error Handling"`
