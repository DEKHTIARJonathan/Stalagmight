# Bugfix: Disable Station/Shot Interactions for Zoom and Pan Tools

## Problem

When Zoom or Pan tool is active, users can still:
- Click to select stations/shots
- See hover effects (stroke width/color changes) on stations/shots
- Right-click to open context menu on stations/shots
- Trigger keyboard shortcuts for selection (Ctrl+A, Delete/Backspace)

This is confusing because these tools should only allow zoom/pan operations, not feature interactions.

## Approach

Disable all station/shot interactions when `activeTool` is `'zoom'` or `'pan'`:

### 1. Define NON_INTERACTIVE_TOOLS in standalone util

Put in standalone util module to avoid Tauri import issues in tests:

```typescript
// src/utils/toolUtils.ts (NEW FILE)
import type { ToolType } from '../store/uiStore';

export const NON_INTERACTIVE_TOOLS: ToolType[] = ['pan', 'zoom'];

export function isNonInteractiveTool(tool: ToolType): boolean {
  return NON_INTERACTIVE_TOOLS.includes(tool);
}
```

Re-export from uiStore for convenience:
```typescript
// In uiStore.ts
export { NON_INTERACTIVE_TOOLS, isNonInteractiveTool } from '../utils/toolUtils';
```

### 2. useMapTools.ts - Add early returns

Check tool at start of each handler. **CRITICAL**: Still call `preventDefault()` to prevent browser defaults.

```typescript
import { isNonInteractiveTool } from '../utils/toolUtils';

  if (isNonInteractiveTool(activeTool)) return;
  // ... existing switch statement
}, [activeTool, ...]);

// Line 187 - handleShotClick

  if (isNonInteractiveTool(activeTool)) return;
  // ... existing logic
}, [activeTool, ...]);

// Line 301 - handleStationHover

  if (isNonInteractiveTool(activeTool)) {
    setHoveredStation(null);
    return;
  }
  setHoveredStation(ref);
}, [activeTool, setHoveredStation]);

// Line 309 - handleShotHover

  if (isNonInteractiveTool(activeTool)) {
    setHoveredShot(null);
    return;
  }
  setHoveredShot(shot);
}, [activeTool, setHoveredShot]);

// Line 317 - handleContextMenu - ALWAYS preventDefault, then check tool
const handleContextMenu = useCallback((target, event) => {
  event.originalEvent.preventDefault();  // ALWAYS prevent native context menu
  if (isNonInteractiveTool(activeTool)) return;  // Skip app context menu
  // ... existing openDialog logic
}, [activeTool, ...]);
```

### 3. SurveyLayer.tsx - Add setActiveTool method

**CRITICAL**: Also call callbacks to clear MapCanvas state (hoveredStation, hoveredShot).

```typescript
import { isNonInteractiveTool, type ToolType } from '../../utils/toolUtils';

private activeTool: ToolType = 'select';

public setActiveTool(tool: ToolType): void {
  const wasNonInteractive = isNonInteractiveTool(this.activeTool);
  const isNonInteractive = isNonInteractiveTool(tool);
  
  this.activeTool = tool;
  
  // Clear hover when switching to non-interactive tool
  if (!wasNonInteractive && isNonInteractive) {
    this.hoveredStationId = null;
    this.hoveredShotId = null;
    this.updateVisualState();
    this.map.getCanvas().style.cursor = '';
    
    // CRITICAL: Also notify callbacks to clear MapCanvas state
    this.callbacks.onFeatureHover?.(false);
    this.callbacks.onStationHover?.(null);
    this.callbacks.onShotHover?.(null);
  }
}
```

Update mouseenter handlers to check tool:
```typescript
this.map.on('mouseenter', this.stationsLayerId, (e) => {
  if (isNonInteractiveTool(this.activeTool)) return;
  // ... existing logic
});

this.map.on('mouseenter', this.shotsLayerId, (e) => {
  if (isNonInteractiveTool(this.activeTool)) return;
  // ... existing logic
});
```

### 4. MapCanvas.tsx - Wire up setActiveTool

**CRITICAL**: Also depend on `mapLoaded` to handle case where tool changed before map loaded.

```typescript
useEffect(() => {
  if (surveyLayerRef.current) {
    surveyLayerRef.current.setActiveTool(activeTool);
  }
}, [activeTool, mapLoaded]);
```

### 5. useKeyboardShortcuts.ts - Disable selection shortcuts

Use `useUIStore.getState().activeTool` and `isNonInteractiveTool()`. **ALWAYS** call `preventDefault()`.

```typescript
import { isNonInteractiveTool } from '../utils/toolUtils';

// Line 114 - Ctrl+A select all
case 'a':
  event.preventDefault();  // ALWAYS prevent browser select-all
  const currentToolA = useUIStore.getState().activeTool;
  if (isNonInteractiveTool(currentToolA)) return;
  // ... existing logic

// Line 193 - Delete/Backspace
if (key === 'delete' || key === 'backspace') {
  const currentToolDel = useUIStore.getState().activeTool;
  if (isNonInteractiveTool(currentToolDel)) return;
  // ... existing logic
}
```

### 6. Edge Cases

- **Tool switch while hovering**: Clear hover immediately via setActiveTool (including store callbacks)
- **Selection persists**: Keep existing selection when switching to pan/zoom
- **Keyboard shortcuts**: Always preventDefault, then skip handler logic
- **Tool changed before map load**: Handled by depending on mapLoaded in useEffect
- **Hover not restored on tool switch back**: Acceptable - user must move mouse
