# Bugfix: Disable Station/Shot Interactions for Zoom and Pan Tools

## Problem

When Zoom or Pan tool is active, users can still:
- Click to select stations/shots
- See hover effects (stroke width/color changes) on stations/shots
- Right-click to open context menu on stations/shots
- Trigger keyboard shortcuts for selection (Ctrl+A, Delete/Backspace)

This is confusing because these tools should only allow zoom/pan operations, not feature interactions.

## Approach

Disable all station/shot interactions when `activeTool` is `'zoom'` or `'pan'`:

### 1. Define NON_INTERACTIVE_TOOLS constant

```typescript
// In uiStore.ts (around line 20, after ToolType)
export const NON_INTERACTIVE_TOOLS: ToolType[] = ['pan', 'zoom'];
```

### 2. useMapTools.ts - Add early returns

Check tool at start of each handler:

```typescript

const handleShotClick = useCallback((sectionId, shotId, event) => {
```

### 3. SurveyLayer.tsx - Add setActiveTool method

```typescript
import { NON_INTERACTIVE_TOOLS, ToolType } from '../../store/uiStore';

private activeTool: ToolType = 'select';

public setActiveTool(tool: ToolType): void {
  const wasNonInteractive = NON_INTERACTIVE_TOOLS.includes(this.activeTool);
  const isNonInteractive = NON_INTERACTIVE_TOOLS.includes(tool);
  
  this.activeTool = tool;
  
  // Clear hover when switching to non-interactive tool
  if (!wasNonInteractive && isNonInteractive) {
    this.hoveredStationId = null;
    this.hoveredShotId = null;
    this.updateVisualState();
    this.map.getCanvas().style.cursor = '';
  }
}
```

Update mouseenter handlers (lines 449 and 478) to check tool:

### 6. Cursor behavior

- Don't change cursor to 'pointer' when hovering features with non-interactive tools
- Keep default cursor or tool-specific cursor (grab for pan, zoom-in for zoom)
- The early return in SurveyLayer mouseenter handlers prevents cursor change naturally

### 7. Edge Cases

- **Tool switch while hovering**: Clear hover immediately via setActiveTool
- **Selection persists**: Keep existing selection when switching to pan/zoom (don't clear)
- **Keyboard shortcuts**: Disable Ctrl+A and Delete/Backspace when pan/zoom active
