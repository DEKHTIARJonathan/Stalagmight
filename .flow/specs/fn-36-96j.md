# Rust Tests: Database Operations

## Overview
Implement comprehensive unit tests for SQLite database operations in `src-tauri/src/persistence/sqlite.rs`. These tests validate data integrity across save/load cycles for projects, sections, shots, merges, and zero datums.

## Scope
- Target: `src-tauri/src/persistence/sqlite.rs`
- Category: Rust Unit Tests

2. Test round-trip save/load for all entity types

4. Test transaction rollback on errors
