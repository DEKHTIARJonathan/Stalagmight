## Objective

Fix Ctrl+drag map panning so it works in select, draw, delete, merge, and measure modes. The feature was intended to allow users to pan the map by holding Ctrl while dragging, without switching to the Pan tool.

---

## Root Cause Analysis

The issue was identified in `src/components/Map/MapCanvas.tsx`:

1. **Line 565 (original):** The keydown handler only enabled `dragPan` when `activeTool === 'select'`, but per requirements it should work in draw, delete, merge, and measure modes as well.

2. **Line 547 (original):** The useEffect for dragPan state also only checked for select mode.

3. **Line 530 (original):** The cursor effect only showed 'grab' cursor in select mode with Ctrl held.

---

## Implementation Details

### File: `src/components/Map/MapCanvas.tsx`

#### 1. Added CTRL_PAN_TOOLS Constant (line 12)
- Defined constant array listing tools that support Ctrl+drag panning
- Tools included: `select`, `draw`, `delete`, `merge`, `measure`
- Tools excluded (have their own drag behaviors): `pan`, `zoom`, `move_section`, `move_station`

#### 2. Updated Cursor Effect (line 533)
- Changed condition from `activeTool === 'select' && ctrlHeld` to `CTRL_PAN_TOOLS.includes(activeTool) && ctrlHeld`
- Now shows 'grab' cursor when Ctrl held in any supported tool

#### 3. Updated DragPan UseEffect (line 550)
- Changed condition from `activeTool === 'select' && ctrlHeld` to `CTRL_PAN_TOOLS.includes(activeTool) && ctrlHeld`
- Enables MapLibre dragPan when Ctrl held in any supported tool

#### 4. Modified Ctrl Keydown Handler (lines 564-574)
- Updated to enable dragPan for all CTRL_PAN_TOOLS, not just select
- Added box select cancellation: when Ctrl is pressed, any active box select is cancelled via `setBoxSelect({ start: null, end: null })`
- This implements the mid-drag Ctrl behavior per user requirements

#### 5. Updated Window Blur Handler (lines 587-593)
- Added box select cancellation on window blur to handle edge case of Ctrl held when switching windows

#### 6. Added Capture-Phase Mousedown Handler (lines 607-626)
- New useEffect that adds a capture-phase event listener on the map container
- Uses `{ capture: true }` to intercept mousedown BEFORE MapLibre's handlers
- Checks `e.ctrlKey` and enables dragPan immediately if in a supported tool
- Fixes timing issue where Ctrl might be pressed just as mouse is clicked
- Properly cleans up listener on unmount

- Tests that 'grab' cursor appears when Ctrl held in each supported tool

#### Describe: Ctrl+Drag Panning Behavior (5 tests)

- Verifies map remains functional after pan operation
- One test per tool: select, draw, delete, merge, measure

#### Describe: Unsupported Tools (4 tests)
- Tests that Ctrl does NOT change cursor to 'grab' in unsupported tools
- Exception: pan tool naturally has 'grab' cursor
- Tests: pan, zoom, move_section, move_station

#### Describe: Box Select Interactions (2 tests)
- `should not start box select when Ctrl+drag in select mode`: Verifies Ctrl+drag doesn't trigger box select overlay
- `should cancel box select when Ctrl pressed mid-drag`: Starts box select, presses Ctrl mid-drag, verifies box select overlay disappears

#### Describe: Edge Cases (5 tests)
- `should handle window blur while Ctrl is held`: Simulates window blur, verifies cursor resets
- `should allow Ctrl+click for selection (not drag)`: Verifies Ctrl+click works without issues
- `should stop showing grab cursor when Ctrl released mid-drag`: Verifies cursor updates when Ctrl released during drag
- `should work with rapid Ctrl press/release cycles`: Stress test with 5 rapid cycles
- `should handle tool switch while Ctrl is held`: Tests switching from select to pan to zoom while Ctrl state changes
