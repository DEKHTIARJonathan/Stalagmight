# Stalagmight user guide

This guide is for people using Stalagmight, the desktop app for processing
underwater cave survey data. Its pages link to each other, so you can start
anywhere and follow the links.

## Workflows

Step-by-step guides that take one task from start to finish.

## Screens

What each screen shows and what its controls do.

## Contributing to this guide

- **Layout:** `workflows/` holds task walkthroughs and `screens/` holds a
  reference page for each screen. Add a new folder when a new kind of page is
  needed, for example concepts or file formats, and list it on this page.
- **Links:** link to a related page instead of repeating it. A workflow step
  links to the page for the screen it happens on, and that screen page links
  back to the workflows that use it.
- **Screenshots:** keep them in `images/`, named after what they show (for
  example `start-screen.png`), so any page can reuse them. Capture the app
  window at 1920 x 1080, starting from a clean profile with no recent projects
  and signed out of SpeleoDB.
- **Data:** use only made-up survey data. A screenshot must never show a real
  survey file, station names, coordinates or account details.
